# 今天也陪着你（astrbot_plugin_daily_companion）

一个轻量的 AstrBot 陪伴插件：让 Bot 拥有自己的一天的日程——起床、吃早餐、
专注做事、午餐午休、摸鱼、晚餐、自由时间、睡觉——并在日程切换和空闲时段
**主动**找用户说话，让用户感到「它在自己生活，也一直惦记着我」。

不依赖 LLM、不依赖任何外部服务，全部文案来自可配置的随机池；核心的日程模型、
五段窗口划分（深夜/早晨/中午/下午/晚上）与默认作息参考了
[astrbot_plugin_private_companion](https://github.com/menglimi/astrbot_plugin_private_companion)。

## 它怎么陪伴你

| 行为 | 说明 |
| --- | --- |
| 日程切换汇报 | 每进入新日程段，随机延迟 10~240 秒后说一句话：早安、去专注啦、干饭时间、晚安…… |
| 空闲随机搭话 | 在「可搭话」的日程段里按概率冒泡：「刚刚在摸鱼休息，突然想看看你在干嘛」 |
| 睡觉/专注不打扰 | 睡觉段和标记为不可搭话的专注段不会触发随机搭话 |
| 免打扰时段 | 默认 23:00-08:00 不随机搭话（日程里的晚安/早安不受影响） |
| 防刷屏 | 每日每用户上限（默认 15 条）、随机搭话最小间隔（默认 40 分钟） |
| 随时查状态 | `陪伴 状态` 看 Bot 现在在做什么、下一段安排；`陪伴 日程` 看一整天 |
| 临时静音 | `陪伴 静音` 暂停主动消息，`陪伴 恢复` 恢复 |

## 内置默认日程

```
07:30-08:10  起床洗漱（迷糊）      <- 早安
08:10-09:00  吃早餐（满足）
09:00-11:50  专心做正事（专注）    <- 「我先去忙啦」
11:50-13:30  午餐和午休（慵懒）
13:30-16:30  下午继续努力（专注）
16:30-17:30  摸鱼休息（放松）
17:30-19:00  晚餐时间（开心）
19:00-21:00  自由时间（放松）
21:00-22:30  洗漱准备睡觉（安静）
22:30-07:30  睡觉（熟睡）          <- 晚安，之后保持安静
```

## 配置

在 AstrBot WebUI 的插件配置页填写：

- **target_users**（必填）：QQ 号（自动按 aiocqhttp 私聊处理）或完整会话标识
  （如 `qq_official:FriendMessage:openid`）。多个用户各自收到陪伴消息。
- **bot_name**：Bot 名字，用于状态播报，默认「小澈」。
- **enable_transition / enable_idle_chat**：两类主动消息开关。
- **idle_chance_per_minute**：每分钟随机搭话概率，默认 0.006（约每小时 0.36 次）。
- **max_daily_messages / min_gap_minutes**：每用户每日上限与最小间隔。
- **quiet_hours**：免打扰时段，默认 `23:00-08:00`，支持跨午夜，留空关闭。
- **custom_schedule**：自定义日程段列表（开始/结束/活动/心情/是否可搭话/进入时
  的话）。非空时完全替换默认日程；结束时间可小于开始时间表示跨午夜；段间空隙
  自动并入前一段。

## 命令

```
陪伴 状态          查看当前活动、已进行时间、下一段、今日主动次数
陪伴 日程 / 日程    查看今天完整日程
陪伴 静音          暂停主动消息（只影响发送者自己）
陪伴 恢复          恢复主动消息
陪伴 帮助          子命令列表
```

## 安装

把本目录复制到 AstrBot 插件目录并重载：

```
Windows: C:\Users\<用户名>\.astrbot\data\plugins\astrbot_plugin_daily_companion
Linux:   ~/.astrbot/data/plugins/astrbot_plugin_daily_companion
```

无第三方依赖。数据（每用户计数、静音状态）保存在插件数据目录的 `state.json`，
删除该文件即完全重置。

## 说明

- 主动消息通过 `context.send_message(unified_msg_origin, ...)` 发送，兼容
  aiocqhttp、qq_official 等提供私聊会话的平台。
- 插件重启后的第一次观察不会立刻播报当前日程段，避免每次重载都打扰；
  从下一段切换开始正常汇报。
